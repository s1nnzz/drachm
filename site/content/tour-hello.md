# Hello, world

<!-- example: hello -->

- `in io;` brings in the `io` module. Nothing is imported for you, so every
  program that prints needs this line.
- `none main()` is where the program starts. `none` means it returns no value.
- `io::outln` prints its text, then a newline. `io::out` prints without the
  newline.
- Every statement ends with `;`. Blocks use `{` and `}`.
